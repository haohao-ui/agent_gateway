## M1 验收

- 不联网、不调用实际模型/Agent、不安装服务；模拟进程与临时 SQLite 可复现。
- 领取/启动/续租/完成/取消均有状态检查；结果 ACK 丢失时可重传。
- 过期租约转 unknown，不重新执行；不支持的恢复操作返回明确错误。
- 进程输出大于保留量不会导致无界内存；UTF-8 尾缓冲有效；父 ctx 取消可等待退出。
- 暂无 HTTP、MCP、配对、UI 不算缺陷，但必须标为下一阶段；M1 不可部署。

## 发布门槛 M4

1. 数据持久化、重启、迁移回滚/恢复演练。
2. 双端 auth/TLS、撤销、越权、限流、日志脱敏与安全依赖检查。
3. 并发/故障矩阵通过；模拟执行与真实 CLI 性能分开报告。
4. macOS arm64/amd64、Linux amd64/arm64、Windows amd64 首批目标；Windows arm64 待依赖与执行器验证后纳入。交叉构建全部覆盖，运行验证记录具体机器。
5. 新旧节点版本协商、能力不兼容拒绝、配置迁移与备份说明。
6. 初步基准目标（待实测校准）：同机模拟无负载派发 P95 < 200ms；100 个空闲节点稳定 30 分钟，无 goroutine/内存持续增长。不得宣传未实测目标为结果。

## 暂缓项

多租户 SaaS、多网关 HA、工作流引擎、NAT 打洞、文件中继、插件市场和自动更新。保留合理接口，不预先制造大量无实现抽象。
