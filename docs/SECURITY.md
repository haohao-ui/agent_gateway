# 安全模型与验收

## 信任边界

网关受信任处理任务内容；本版本不承诺任务内容对网关端到端保密。网络不可信，节点可能失窃，调用者权限不同，工作区内容/Agent 输出不可信。节点运行在用户账号权限下时，该账号拥有的资源不能仅靠 cwd 隔离。

## 必须实现

- 一次邀请、短期过期、配额/速率限制；首次通过 CA 或独立确认的指纹建立服务器信任。节点本地产生私钥。
- mTLS 设备身份与注册设备绑定；连接成功仍检查撤销状态和设备权限；短期证书轮换与恢复。不传管理员密钥到节点。
- 管理/MCP 凭据分角色和设备/工作区范围，可撤销、可轮换。Web 用 HttpOnly/Secure/SameSite 会话、CSRF、Origin/Host 检查与 CSP。
- 避免回环 HTTP 被代理误当可信；可信代理显式配置，禁止任意 X-Forwarded-* 决定安全边界。开发明文只绑定回环，必须显式 dev 模式。
- 节点策略拒绝未知能力、未授权工作区/路径、远端新增 argv 或提高额度。提示词不是策略。
- 根目录约束使用安全打开 API；限制普通文件、大小、并发。下载验证对端设备身份，不把“私网地址”视为可信；支持 VPN 地址配置。
- 日志、进程参数、测试输出、Git 不泄露凭据。节点执行环境不得继承控制平面管理凭据。
- 签名发行、校验和、依赖漏洞检查；升级保留数据库/配置备份和版本兼容策略，发布前验证回滚限制。

## 故障与攻击验收

缺失/错误/过期/撤销凭据、A 设备冒充 B、查看他人任务、过期/重放租约、取消与完成竞争、领取响应丢失、结果 ACK 丢失、节点崩溃、网关重启、中文大输出、日志洪泛、符号链接替换、文件中途变化、跨源重定向、未授权路径、磁盘满、慢客户端。

## 不可夸大

单元测试通过不等于三平台验收。Job Objects/进程组不是完整沙箱。租约防止旧结果覆盖，不保证外部副作用停止。SHA-256 不是发送者身份认证。文件一次会话允许恢复，不宣传第一次 GET 后立即消费。未知执行不能自动当失败重跑。
