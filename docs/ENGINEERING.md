# 代码开发规范

## 设计与代码

- Go 1.27.1，gofmt；小包、显式构造函数、依赖注入，禁止包初始化启动 goroutine/网络服务或修改文件。
- 核心领域不依赖 HTTP、MCP、SQLite 驱动。接口定义在使用方，避免为每个类型机械创建接口。
- 不使用全局可变业务状态；ctx 为首参数并传播；所有后台 goroutine 有归属、取消和等待退出机制。
- UTC 时间持久化、可注入时钟测试租约；跨进程持久时间不得只用 monotonic。限制系统时钟漂移影响并在节点诊断展示。
- 错误用稳定 code + 可读 message；errors.Is/As 判断，不匹配字符串。保留内部 cause，不对外泄露凭据、SQL 或文件内容。
- 注释解释约束、事务与竞态；导出 API 写注释。JSON 字段 snake_case，明确必填/可选、字节限制和兼容性。
- 禁止任意 shell 拼接。执行文件/参数模板仅本地配置；环境白名单。标准输出/错误持续消费，超过保留量仍须 drain。
- 文件写入明确权限、临时文件与原子替换；凭据避免命令行传参和日志。Windows 使用 ACL，不能把 chmod 当跨平台隔离。
- SQL 参数化；迁移有版本、事务和失败恢复测试；业务原子操作不能拆成无保护的读后写。
- 依赖只由协调者增加/升级，固定 go.mod/go.sum；无 ORM/重型框架/动态 Go 插件；不为了少依赖自写密码学。

## 权限与资源

所有 mutation 必须认证/授权。节点本地策略不可被远端扩权。请求解析前限制字节数；能力输入做严格验证，不使用任意 map 隐式接受权限参数。HTTP client 默认验证 TLS、拒绝跨源重定向；server 明确 header/body/idle 超时；长轮询单独设置 deadline。

队列、订阅者、日志、磁盘、并发、执行时长均有上限。审计记录 actor/action/resource/outcome/time，不记录令牌、完整 prompt、私钥或原始敏感输出。秘密不得提交到仓库。

## 测试分层

1. 领域：非法状态转换、去重冲突、过期租约、旧 attempt、取消竞争。
2. 存储：临时真实 SQLite、重开恢复、并发领取、迁移失败回滚。
3. 执行：使用 Go 测试辅助进程，不依赖 Python/sh/真实 Agent；验证大输出、中文、超时、进程树和环境隔离。
4. 通信：httptest + 临时 CA，认证/越权/断连/重复消息；不以关闭 TLS 验证通过测试。
5. 集成：模拟节点真实 HTTP 提交到结果，故障注入；MCP 真正初始化、列工具、调用，不能仅 curl health。
6. 平台：交叉编译与对应 OS 的真实运行分别记录，不能相互代替。

## 合并门槛

```sh
gofmt -l ./internal ./cmd
go vet ./...
go test ./...
go test -race ./...
git diff --check
```

目录未创建时只检查已有目录。race 在支持的平台和工具链运行，不能因目标无 race 支持而谎报。跨平台用 CGO_ENABLED=0 构建产品、`go test -exec=true ./...` 或逐包 `go test -c` 只证明编译，不证明执行。govulncheck 在 release gate 执行并记录版本/输出。

每个安全或恢复特性须有能发现真实故障的测试；不写只复刻实现的测试。完成后扩大测试仅针对新风险。报告成功、失败、未验证分别列明。

## Git 与协作

每位 worker 独立 worktree。提交小而完整，标题说明行为；禁止覆盖他人修改、强推、删除未知文件。共享契约只能由协调者更新。公共 API 变更先写 proposed change，不自行改签名。每次 handoff 附路径、命令、输出摘要、剩余问题；状态不是用测试数量代替验收。
